# Contributing

Issues and pull requests are welcome.

Before submitting a change:

1. Keep the integration under `custom_components/lacrosse_jeelink/`.
2. Keep Home Assistant setup UI-based; do not add new YAML-only configuration.
3. Run the repository validation workflows (HACS and hassfest).
4. Test against a real Jeelink receiver when changing serial or radio handling.
5. Update `CHANGELOG.md` for user-visible changes.
